PORTFOLIO AGROCERES BINOVA - Android offline build

This package keeps the existing HTML and images bundled into the Android app.
The app itself does not require an internet connection to open or navigate.
External website/social links inside the portfolio still require internet when opened.

Build without local Android/Node installation:
1. Upload this folder to a GitHub repository.
2. Open Actions > Build Android APK > Run workflow.
3. Download the artifact named portfolio-agroceres-binova-apk.
4. Extract it and install app-debug.apk on an Android phone.
